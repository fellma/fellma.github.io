블로그 글 작성 도우미 개인정보처리방침

시행일: 2026년 8월 12일 · 최종 수정일: 2026년 8월 12일

「블로그 글 작성 도우미」(이하 “앱”)는 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 방침은 앱이 어떤 정보를 처리하는지, 어떻게 보호하는지 설명합니다.

1. 수집·처리하는 정보

앱은 별도의 회원가입 없이 사용할 수 있습니다. 아래 정보는 이용자가 직접 입력하거나, 기능 사용 과정에서 처리될 수 있습니다.

  • 설정 정보: Gemini API 키, 네이버 블로그 URL, 학습된 글쓰기 스타일, 브랜드명, 앱 설정값
  • 사진: 이용자가 업로드한 시공·일상 사진(기기 갤러리에서 선택)
  • 현장 힌트: 이용자가 입력한 선택적 텍스트
  • 생성 결과: AI가 만든 블로그 초안 텍스트
  • 광고 식별 정보: Google AdMob을 통한 광고 제공 시 Google이 수집할 수 있는 기기·광고 관련 정보

앱 운영자는 별도의 서버를 운영하지 않으며, 이용자의 정보를 운영자 서버에 저장·전송하지 않습니다.

2. 정보의 처리 목적

  • 네이버 블로그 RSS를 통해 글 문체 학습
  • 업로드한 사진 분석 및 전·후 묶음 생성
  • 학습된 문체로 블로그 초안 작성
  • 글·사진 클립보드 복사 및 갤러리 저장 기능 제공
  • 앱 설정 저장 및 기능 제공
  • Google AdMob을 통한 광고 표시

3. 제3자 제공 및 외부 서비스 연동

앱은 아래 외부 서비스와 연동됩니다. 해당 서비스 이용 시 각 사업자의 개인정보처리방침이 적용됩니다.

  • Google Gemini API
    이용자가 입력한 API 키를 사용하여, 업로드한 사진·블로그 학습 데이터·현장 힌트가 Google 서버로 전송되어 AI 분석 및 글 생성에 사용됩니다.
    Google 개인정보처리방침
  • 네이버 블로그 RSS
    이용자가 입력한 블로그 주소의 공개 RSS를 읽어 글 문체 학습에 사용합니다. 네이버 계정 비밀번호는 수집하지 않습니다.
  • Google AdMob
    배너·전면 광고 표시를 위해 Google이 광고 ID 등 정보를 수집·처리할 수 있습니다.
    Google 광고 정책

4. 정보의 저장 및 보관

  • 설정 정보(Gemini API 키 포함)는 이용자 기기 내부에 저장됩니다.
  • 업로드한 사진은 앱 사용 중 기기 메모리에서 처리되며, 사진 복사 기능 사용 시 갤러리 Pictures/블로그글작성도우미 폴더에 저장될 수 있습니다.
  • 앱 삭제 시 기기에 저장된 앱 데이터는 일반적으로 함께 삭제됩니다.
  • Google Gemini·AdMob으로 전송된 데이터의 보관 기간은 각 서비스 제공자의 정책을 따릅니다.

5. 접근 권한

앱은 다음 권한을 사용할 수 있습니다.

  • 인터넷: 블로그 RSS 조회, Gemini API 호출, 광고 로드
  • 사진·미디어(READ_MEDIA_IMAGES): 갤러리에서 사진 선택
  • 저장소(구버전 Android): 사진 저장·불러오기

권한은 해당 기능 사용 시에만 필요하며, 이용자는 기기 설정에서 권한을 거부할 수 있습니다.

6. 이용자의 권리

이용자는 언제든지 아래 방법으로 자신의 정보를 관리할 수 있습니다.

  • 앱 설정에서 API 키·블로그 URL 등 정보 수정 또는 삭제
  • 앱 삭제를 통한 기기 내 저장 데이터 삭제
  • Google Gemini·AdMob 관련 설정은 Google 계정 및 기기 광고 설정에서 관리

7. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

8. 개인정보처리방침의 변경

법령 또는 서비스 변경에 따라 본 방침이 수정될 수 있습니다. 변경 시 본 페이지의 시행일·수정일을 갱신합니다.
